# GR-120N 到達図 V1

TADANO GR-120N-1 の作業半径-揚程図を元PDFからベクターのまま抽出し、現場入力値をSVGで重ねるGitHub Pages用Webアプリ。

## V1仕様
- 23.8mフルブーム固定
- 3.6mジブ / 5.5mジブ
- ジブオフセット45°固定
- 入力: 旋回芯から建物までの距離、建物高さ
- 自動出力: ブーム角、作業半径、建物奥への到達距離、先端高さ
- クリアランス余裕、ブームたわみ、フック寸法、定格荷重判定は対象外

## 拡張
`data/gr120n.json` に機種・ジブ角・座標校正データを分離しているため、25°/5°や別機種を追加可能。
